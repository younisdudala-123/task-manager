# 🚀 Task Manager Pro

A simple and modern **Task Management Web Application** built using HTML, CSS, and JavaScript.  
This project helps users create, update, delete, and track their daily tasks efficiently.

---

## 📌 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 📊 Track task status (Pending / In Progress / Completed)
- 🎯 Priority system (Low / Medium / High)
- 🔍 Search tasks
- 📈 Progress bar tracking completed tasks
- 💾 Data saved using LocalStorage (no backend required)
- 🎨 Modern glassmorphism UI design

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Glassmorphism UI + Animations)
- JavaScript (DOM + LocalStorage)
